# بوت تداول العملات الرقمية

بوت يشتغل بروحه على Binance. كل 5 دقايق يسوي هالشغلات:

1. **يجيب معلومات السوق** من 3 مصادر عالمية:
   - **Binance:** أسعار وحجم تداول كل العملات.
   - **CoinGecko:** العملات اللي الناس تدور عليها هسه (trending).
   - **مؤشر الخوف والطمع (Fear & Greed):** شكد السوق خايف أو طماع.
2. **يشوف حالة البتكوين.** إذا البتكوين نازل والسوق طماع، ما يشتري. وإذا الوضع مو واضح، يشتري بنص المبلغ.
3. **يفحص أكثر 40 عملة تداولاً، ويه العملات الترند،** ويدور على نوعين من الفرص:
   - **انفجار (breakout):** العملة كسرت أعلى سعر إلها بآخر 20 ساعة، والتداول عليها صار ضعفين أو أكثر.
   - **نزلة بترند صاعد (dip):** عملة صاعدة على المدى الطويل، نزلت هواية، وهسه رجعت تصعد.
4. **يشتري أقوى الفرص** (أقصى شي 4 عملات بنفس الوقت).
5. **يبيع لحاله:**
   - **وقف خسارة لكل صفقة:** ما يخسر بالصفقة الوحدة أكثر من 1% من رأس المال.
   - **وقف متحرك:** من تربح الصفقة، الوقف يصعد ويه السعر حتى يحافظ على الربح.
   - **حد زمني:** إذا العملة ما تحركت خلال 72 ساعة، يبيعها.

## الحماية
- **البوت ما يگدر يسحب فلوسك.** إذا المفتاح بي صلاحية سحب، البوت يرفض يشتغل.
- **حد خسارة يومي:** إذا خسر 5% بنفس اليوم، يوگف شراء لباچر.
- **حد خسارة كلي:** إذا نزلت الفلوس 30% عن أعلى رقم وصلته، يوگف شراء نهائياً.

> ⚠️ هذا البوت ما يعرف المستقبل. ممكن يربح وممكن يخسر. حط بس المبلغ اللي عادي تخسره.

## التشغيل على الموبايل (أندرويد)

1. نزّل تطبيق **Termux** من متجر **F-Droid** (نسخة Play Store قديمة وما تشتغل زين).
2. افتح Termux واكتب هالأوامر وحدة وحدة:
   ```
   pkg install -y python git
   git clone https://github.com/ahmadalasady2002-del/-new-project bot
   cd bot
   git checkout claude/trading-bot
   cp .env.example .env
   termux-wake-lock
   ./run.sh
   ```
3. البوت هسه يشتغل **بفلوس وهمية (100$)**. خليه أسبوعين وشوف النتيجة.
4. خلي التلفون على الشاحن وخلي Termux مفتوح، وطفي "توفير البطارية" عن Termux.

**تشوف النتيجة:** افتح جلسة ثانية بـ Termux (اسحب من يسار الشاشة ← New session) واكتب:
```
cd bot && python -m bot.main --report
```

## التحويل لفلوس حقيقية

1. من تطبيق Binance سوّي **API key**:
   - شغّل **Enable Spot & Margin Trading** بس.
   - **لا تشغّل Enable Withdrawals أبد.**
2. بـ Termux اكتب `nano .env` وحط المفتاحين، وغيّر `LIVE_TRADING=no` إلى `LIVE_TRADING=yes`.
3. احذف ملف التجربة: `rm state.json`
4. شغّله مرة ثانية: `./run.sh`

البوت يتداول بالـ USDT اللي موجود بحساب Spot.

## تغيير الإعدادات
كل إعداد موجود بملف `bot/config.py`، وتگدر تغيّره من ملف `.env`. مثلاً حتى تخلي البوت ما يمسك أكثر من عملتين بنفس الوقت، اكتب بملف `.env`:
```
MAX_POSITIONS=2
```
