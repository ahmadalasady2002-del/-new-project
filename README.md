# حاسبة الذهب — العراق

حاسبة عربية (RTL) لحساب سعر الذهب وأجور الصياغة بالدينار العراقي، بثلاث خطوات:

1. **سعر الغرام** = سعر المثقال ÷ 5
2. **سعر الغرام النهائي** = سعر الغرام + أجور الصياغة لكل غرام
   (المصنعية الثابتة للقطعة تُوزَّع على الوزن: المبلغ ÷ الوزن)
3. **السعر النهائي** = سعر الغرام النهائي × وزن القطعة

مثال: 980,000 د.ع للمثقال، 7.35 غرام، 12,000 د.ع صياغة للغرام ← **1,528,800 د.ع**.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # نسخة الإنتاج في dist/
npm test         # اختبارات منطق الحساب
```

## التقنيات

React 19 · Tailwind CSS 4 · Lucide Icons · Vite

## البنية

```
src/
  lib/gold.js              منطق الحساب والتنسيق وتنظيف المدخلات (+ gold.test.js)
  hooks/                   الحفظ المحلي، الوضع الليلي، تحريك الأرقام
  components/
    StepCard.jsx           بطاقة الخطوة مع الخط الزمني
    Equation.jsx           عرض المعادلة بالأرقام الفعلية
    NumberField.jsx        حقل رقمي بفواصل الآلاف ويمنع القيم السالبة
    Segmented.jsx          اختيار العيار ونوع المصنعية
    ResultsPanel.jsx       النتائج + نسخ / واتساب / إعادة تعيين
    MobileTotalBar.jsx     شريط السعر العائم على الموبايل
  App.jsx
```

> الأسعار تُدخل يدوياً وليست أسعار سوق مباشرة. تعتمد الحاسبة المثقال العراقي = 5 غرامات.
